## Quick Start

### 1 — Install dependencies

```bash
pip install -r requirements.txt
```

### 2 — Train the model

```bash
python -m src.train data/ai_writing_detection_dataset.csv models/pipeline.pkl
```

Trains an XGBoost classifier, runs stratified 5-fold cross-validation, prints metrics, and saves the full sklearn Pipeline to `models/pipeline.pkl`.

### 3 — Start the API backend

```bash
uvicorn src.api:app --reload --port 8000
```

Interactive API docs available at **http://localhost:8000/docs**

### 4 — Start the Streamlit frontend

```bash
streamlit run app.py
```

Opens at **http://localhost:8501**

### 5 — Run the tests

```bash
pytest tests/ -v
```

## Preprocessing Pipeline (`src/preprocess.py`)

The pipeline is **fully self-contained** — it accepts raw DataFrames at inference time and applies all transformations internally via a sklearn `Pipeline`:

```
FunctionTransformer          ratio features + log1p on skewed columns
    └── ColumnTransformer
            ├── numeric      SimpleImputer(median)  →  RobustScaler
            └── categorical  SimpleImputer(most_frequent)  →  OneHotEncoder
```

**Engineered features** (computed inside the pipeline, zero-division safe):

| Feature | Formula |
|---|---|
| `words_per_minute` | `Word_Count / (Editing_Time + 1)` |
| `revision_density` | `Revision_Count / (Word_Count + 1)` |
| `lexical_diversity` | `Unique_Words / (Total_Words + 1)` |

**Log-transformed columns** (right-skewed telemetry): `Editing_Time`, `Revision_Count`, `Grammar_Errors`, `Typing_Speed`

## Model (`src/train.py`)

- **Algorithm:** XGBoost binary classifier (`XGBClassifier`)
- **Class imbalance:** `scale_pos_weight = n_negative / n_positive` (≈ 5.91), computed at fit-time from training labels — no resampling overhead
- **Validation:** Stratified 5-fold cross-validation (reporting only — no leakage into final model)
- **Artifact:** Full sklearn `Pipeline` (preprocessor + classifier) saved to `models/pipeline.pkl` via joblib

### Results (real dataset, 10,000 records, 80/20 split)

| Evaluation | ROC-AUC | F1 (Macro) | Precision | Recall | Accuracy |
|---|---|---|---|---|---|
| 5-Fold CV (mean) | 1.0000 | 0.9992 | 0.9991 | 0.9994 | 0.9996 |
| Held-out Test Set | 1.0000 | 1.0000 | 1.0000 | 1.0000 | 1.0000 |

> Near-perfect scores are expected — behavioral telemetry features (`Typing_Speed`, `Editing_Time`) are by design highly discriminative in this research dataset.

## API Reference (`src/api.py`)

Base URL: `http://localhost:8000`

### `GET /health`

```json
{ "status": "ok", "model_loaded": true }
```

### `GET /model/info`

```json
{
  "pipeline_steps": ["preprocessor", "classifier"],
  "n_features_in": 18,
  "model_path": "models/pipeline.pkl"
}
```

### `POST /predict`

**Request body** — all 18 feature columns. Required: `Word_Count`, `Submission_Hour`. All telemetry numerics are optional (dataset has real NULLs; pipeline imputes them).

```json
{
  "Submission_Type": "Essay",
  "Academic_Level": "Undergraduate",
  "Primary_Language": "Native",
  "Word_Count": 800,
  "Editing_Time": 90.0,
  "Revision_Count": 5.0,
  "Typing_Speed": 45.0,
  "Submission_Hour": 14,
  "..."
}
```

**Response:**

```json
{
  "label": "Human",
  "is_ai": 0,
  "probability_ai": 0.404258,
  "confidence": 0.595742
}
```

### `POST /predict/batch`

```json
{ "records": [ <PredictRequest>, ... ] }
```

```json
{
  "predictions": [ { "label": "Human", "is_ai": 0, "probability_ai": 0.40, "confidence": 0.60 } ],
  "count": 1
}
```

Minimum 1 record required (Pydantic `min_length=1`; returns HTTP 422 on empty list).

## Development Notes

- **No data leakage:** The preprocessor is fit only on `X_train`. `X_test` and all API payloads go through `transform()` only.
- **Self-contained pipeline:** Feature engineering (ratios, log transforms) lives inside the sklearn `Pipeline` as a `FunctionTransformer` step, so `models/pipeline.pkl` is the single inference artifact — no pre-processing code needed at serving time.
- **Null safety:** All optional numeric columns accept `None`; `pd.to_numeric(..., errors='coerce')` converts them to `NaN` before log-transforming, preventing `ufunc` errors.
- **TDD:** Tests were written before implementation in every module (red → green → commit).
